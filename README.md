# Arbor — карта места на диске

Десктоп-приложение (Electron + React), которое сканирует выбранную папку и показывает, сколько места занимает каждая вложенная директория — в виде графа с линиями.

Толщина линии пропорциональна объёму. Клик по узлу углубляет диаграмму.

## Запуск

```bash
npm install
npm run electron
```

Откроется окно приложения. Нажмите **Обзор**, выберите папку или введите путь вручную, затем **Показать**.

Браузерный предпросмотр UI (без доступа к произвольным системным путям):

```bash
npm start
```

В браузере доступна кнопка **Демо** с примером дерева.

Сборка production и запуск Electron:

```bash
npm run electron:prod
```

## Возможности

- Выбор папки через системный диалог или ввод пути
- Рекурсивный подсчёт размеров файлов и папок
- SVG-граф: узлы + кривые связи, анимация появления
- Drill-down по папкам и хлебные крошки
- Список содержимого с полосками долей
- Пропуск тяжёлых каталогов вроде `node_modules` и `.git` при обходе

## Стек

- Electron (доступ к файловой системе)
- React + TypeScript
- d3-hierarchy (раскладка дерева)
