# Telegram-бот заявок LockerWood

## Быстрый старт

1. Откройте [@BotFather](https://t.me/BotFather) → `/newbot` → скопируйте токен.
2. Впишите в `server/.env`:
   ```
   TELEGRAM_BOT_TOKEN=123456:ABC...
   TELEGRAM_ADMIN_IDS=
   ```
3. Напишите боту `/start` со своего аккаунта.
4. Откройте в браузере:
   `https://api.telegram.org/bot<TOKEN>/getUpdates`
   Найдите `message.from.id` (число) и добавьте в:
   ```
   TELEGRAM_ADMIN_IDS=123456789
   ```
   Несколько админов — через запятую: `111,222`.
5. Перезапустите сервер (`npm run start:dev` в `server/`).

Если `TELEGRAM_BOT_TOKEN` пустой, бот не стартует: сайт и API работают как раньше.

## Возможности

- Новая заявка с сайта → сообщение в личку всем id из whitelist.
- Кнопки **Активна / Завершена / Отменена** меняют статус в БД.
- У отменённых — **Удалить навсегда** (с подтверждением).
- Меню как в админке:
  - `/menu` или кнопки клавиатуры: Активные / Завершённые / Отменённые
  - фильтр Все / Заказы / Консультации
  - в отменённых — «Удалить все» для текущего фильтра
- Команды: `/active`, `/completed`, `/canceled`, `/help`
