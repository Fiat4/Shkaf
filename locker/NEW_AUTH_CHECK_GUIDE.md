# 🔒 Новый подход к защищенным маршрутам

## 💡 Идея:

Создать отдельный хук `useAuthCheck` для проверки авторизации, который:
- Делает простой запрос на `/admin/check`
- Не зависит от сложной логики обновления токенов
- Возвращает четкий результат: авторизован или нет

### 2. **Обновленный `ProtectedRoute`**
```typescript
const ProtectedRoute = ({ children }) => {
    const { isAuthenticated, loading, error } = useAuthCheck();
    
    useEffect(() => {
        if (!loading && !isAuthenticated) {
            navigate('/admin/login');
        }
    }, [isAuthenticated, loading, navigate, error]);
};
```

## 🔄 Как работает:

### **При загрузке защищенного маршрута:**
1. `useAuthCheck` делает запрос на `/admin/check`
2. Если ответ 200 - пользователь авторизован
3. Если ответ 401 - пользователь не авторизован
4. `ProtectedRoute` редиректит на логин

### **Преимущества:**
- ✅ Простая логика без сложных интерсепторов
- ✅ Четкий результат: авторизован или нет
- ✅ Не зависит от обновления токенов
- ✅ Быстрая проверка (5 секунд таймаут)
