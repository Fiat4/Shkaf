# Аутентификация в админ панели

## Обзор
Реализован полноценный функционал входа в админ панель с JWT аутентификацией и автоматическим перехватчиком для обработки 401 ошибок.

## Созданные файлы

### 1. `src/hook/useAuth.tsx`
Основной хук для аутентификации с axios интерсепторами:
- Автоматическое добавление JWT токена к запросам
- Перехват 401 ошибок с редиректом на страницу логина
- Сохранение/загрузка токена из localStorage
- Проверка валидности токена при инициализации

**Основные методы:**
- `login(credentials)` - вход в систему
- `logout()` - выход из системы
- `getAuthenticatedApi()` - получение настроенного axios экземпляра

### 2. `src/hook/useAdminApi.tsx`
Хук для работы с админ API:
- Использует аутентифицированный axios из useAuth
- Предоставляет методы для работы с продуктами, отзывами, заказами
- Обработка ошибок и состояний загрузки

### 3. `src/Components/ProtectedRoute/ProtectedRoute.tsx`
Компонент для защиты маршрутов:
- Проверяет аутентификацию пользователя
- Автоматически перенаправляет на страницу логина
- Показывает индикатор загрузки

### 4. Обновленные компоненты
- `AdminLoginPage.tsx` - интегрирован с useAuth хуком
- `AdminPage.tsx` - добавлена кнопка выхода и информация о пользователе
- `AdminMain.tsx` - пример использования useAdminApi

## Использование

### Вход в систему
```tsx
const { login, loading, isAuthenticated } = useAuth();

const handleLogin = async () => {
    const result = await login({ login: 'admin', password: 'password' });
    if (result.success) {
        // Успешный вход
    } else {
        // Ошибка входа
        console.error(result.error);
    }
};
```

### Защищенные маршруты
```tsx
<Route path="/admin" element={
    <ProtectedRoute>
        <AdminPage />
    </ProtectedRoute>
} />
```

### API запросы
```tsx
const { getAllProducts, loading, error } = useAdminApi();

useEffect(() => {
    const loadProducts = async () => {
        try {
            const products = await getAllProducts();
            console.log(products);
        } catch (error) {
            console.error('Ошибка загрузки:', error);
        }
    };
    
    loadProducts();
}, []);
```

## Настройка бэкенда

Убедитесь, что на бэкенде реализованы следующие эндпоинты:

1. `POST /auth/login` - вход в систему
   ```json
   {
     "login": "admin",
     "password": "password"
   }
   ```
   Ответ:
   ```json
   {
     "token": "jwt_token_here",
     "user": {
       "id": "1",
       "login": "admin",
       "role": "admin"
     }
   }
   ```

2. `GET /auth/verify` - проверка токена (опционально)
   Headers: `Authorization: Bearer <token>`

3. `POST /auth/logout` - выход из системы (опционально)

## Особенности

- **Автоматический редирект**: При получении 401 ошибки пользователь автоматически перенаправляется на `/admin/login`
- **Сохранение сессии**: Токен сохраняется в localStorage и восстанавливается при перезагрузке страницы
- **Типизация**: Полная типизация TypeScript для всех интерфейсов и методов
- **Обработка ошибок**: Централизованная обработка ошибок с понятными сообщениями
- **Состояния загрузки**: Индикаторы загрузки для улучшения UX

## Безопасность

- JWT токены автоматически добавляются к каждому запросу
- При истечении токена происходит автоматический выход
- Все админ маршруты защищены проверкой аутентификации
- Токены хранятся в localStorage (можно рассмотреть httpOnly cookies для повышения безопасности)
