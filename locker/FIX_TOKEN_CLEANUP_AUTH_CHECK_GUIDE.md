# 🗑️ Исправление удаления токена из localStorage в useAuthCheck

## ✅ Что исправлено:

### **Добавлено удаление токена при ошибке авторизации**
```typescript
} catch (error: any) {
    console.log('❌ Авторизация не подтверждена:', error.response?.status);
    
    // Удаляем токен из localStorage при ошибке авторизации
    localStorage.removeItem('adminToken');
    console.log('🗑️ Токен удален из localStorage');
    
    setAuthState({
        isAuthenticated: false,
        loading: false,
        error: error.message,
    });
    
    return false;
}
```

## 🔄 Как теперь работает:

### **При ошибке авторизации (401):**
1. `useAuthCheck` делает запрос на `/admin/check`
2. Получает 401 ошибку (токен истек или недействителен)
3. **Автоматически удаляет токен** из localStorage
4. Устанавливает `isAuthenticated: false`
5. `ProtectedRoute` редиректит на логин

### **При успешной авторизации:**
1. `useAuthCheck` делает запрос на `/admin/check`
2. Получает 200 ответ
3. Устанавливает `isAuthenticated: true`
4. Пользователь попадает в админ панель

## 🧪 Как тестировать:

### 1. **Войдите в систему** на `/admin/login`
### 2. **Перейдите в админ панель** - токен должен быть в localStorage
### 3. **Дождитесь истечения токена** (20 секунд)
### 4. **Обновите страницу** - токен должен быть удален из localStorage
### 5. **Проверьте DevTools** → Application → Local Storage

## 🎯 Ожидаемый результат:

Теперь система должна:
- **Автоматически удалять токен** при ошибке авторизации
- **Очищать localStorage** при истечении токена
- **Корректно работать** с состоянием авторизации
- **Не оставлять мусор** в localStorage
