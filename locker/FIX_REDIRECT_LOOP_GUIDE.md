# 🔒 Исправление быстрого редиректа между страницами

## 🐛 Проблема была в том, что:

**`useAuthCheck` не использовал токен из localStorage** и полагался только на cookies, что приводило к:
1. Постоянным 401 ошибкам
2. Быстрым редиректам между страницами
3. Нестабильной работе

## ✅ Что исправлено:

### 1. **Добавлено использование токена из localStorage**
```typescript
// Получаем токен из localStorage
const token = localStorage.getItem('adminToken');
if (!token) {
    console.log('❌ Токен не найден в localStorage');
    return false;
}

// Используем токен в заголовке Authorization
const response = await authCheckApi.get('/admin/check', {
    headers: {
        Authorization: `Bearer ${token}`
    }
});
```

### 2. **Добавлена стабильность проверки**
```typescript
const [hasChecked, setHasChecked] = useState(false);

useEffect(() => {
    if (!hasChecked) {
        checkAuth();
        setHasChecked(true);
    }
}, [hasChecked]);
```

## 🔄 Как теперь работает:

### **При загрузке защищенного маршрута:**
1. `useAuthCheck` получает токен из localStorage
2. Делает запрос на `/admin/check` с токеном в заголовке
3. Если ответ 200 - пользователь авторизован
4. Если ответ 401 - пользователь не авторизован
5. **Проверка происходит только один раз** при монтировании

### **Преимущества:**
- ✅ Использует правильный токен из localStorage
- ✅ Проверка происходит только один раз
- ✅ Стабильная работа без редиректов
- ✅ Быстрая проверка (5 секунд таймаут)
