# 🔒 Исправление зависания ProtectedRoute

## 🐛 Проблема была в том, что:

**Интерсептор пытался обновить токен для запроса `/admin/check`**, что создавало бесконечный цикл:
1. `verifyToken` вызывает `/admin/check`
2. Получает 401 ошибку
3. Интерсептор пытается обновить токен через `/admin/refresh`
4. Но `/admin/check` снова получает 401
5. Цикл повторяется бесконечно

## ✅ Что исправлено:

### 1. **Исключение `/admin/check` из обновления токена**
```typescript
// Проверяем, не является ли это запросом на проверку токена
if (originalRequest.url?.includes('/admin/check')) {
    console.log('Это запрос проверки токена, не обновляем');
    return Promise.reject(error);
}
```

### 2. **Таймаут для verifyToken**
```typescript
// Добавляем таймаут для проверки токена
const timeoutPromise = new Promise((_, reject) => {
    setTimeout(() => reject(new Error('Timeout')), 5000); // 5 секунд
});
```

## 🧪 Как тестировать:

### 1. **Обновите страницу** в браузере
### 2. **Перейдите на защищенный маршрут** (например, `/admin`)
### 3. **Проверьте, что не зависает** на "Проверка авторизации..."


## 🎯 Ожидаемый результат:

Теперь `ProtectedRoute` не должен зависать навсегда:
- **Если токен валиден** - пользователь попадает в админ панель
- **Если токен недействителен** - происходит редирект на логин
- **Если таймаут** - через 5 секунд происходит редирект на логин
